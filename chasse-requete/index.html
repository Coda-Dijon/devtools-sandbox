Chasse aux requêtes

Nous allons utiliser les devtools pour suivre les requêtes qui ont lieu dans une page simple.

1 - Etudie les requêtes dans l'onglet Réseau

  1. Ouvre les devtools.
  2. Rends-toi dans l'onglet "Network" (ou "Réseau")
  3. Rafraichis la page et observe ce qui se passe dans l'onglet réseau (n'hésite pas à cliquer sur les lignes comme `chasse-requete`, `Canard.png`
  4. Après avoir cliqué sur une ressource comme `chasse-requete`, regarde l'onglet `Headers`.

Pour chaque ressource : `chasse-requete`, `Canard.png`, regarde l'onglet "Headers" (En-têtes)

Note les informations suivantes:

État (Status)
ex. 200
Name (Fichier)
ex. /chasse-requete/
Type
ex. html (Document), css (Stylesheet), png, js
Domaine
ex. foo.bar
URL de la requête
ex. https://foo.bar/pikachu.png

2 - Etudie l'ordre des requêtes

  1. Rafraichis plusieurs fois la page et note dans quel ordre se font les requêtes
  2. Que remarques-tu ?
  3. Affiche le code source de la page.
  4. Dessine la séquence

3 - Où est le mage ?

Une image est manquante.

  1. Quel est le problème ?
  2. Quelles entêtes HTTP sont retournées ?

Indice : Joue avec les autres onglets des devtools.
