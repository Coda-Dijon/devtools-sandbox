DevTools

Les navigateurs incluent des outils pour les développeurs

Différentes façons d'ouvrir les DevTools

Raccourcis clavier

Panneau Windows / Linux macOS
Dernier panneau utilisé F12 ou Ctrl+Maj+I Cmd+Option+I
Éléments (mode inspection) Ctrl+Maj+C Cmd+Option+C
Console Ctrl+Maj+J Cmd+Option+J

Clic droit

Faites un clic droit sur un élément de la page → Inspecter. DevTools s'ouvre directement sur le panneau Éléments avec le nœud sélectionné dans l'arborescence DOM.

Menu du navigateur

  • Chrome / Edge : ⋮ → Plus d'outils → Outils de développement
  • Firefox : ☰ → Outils supplémentaires → Outils de développement web
  • Safari : Développement → Afficher l'inspecteur web (à activer d'abord via Réglages → Avancées → Afficher les fonctions pour les développeurs web)

Barre d'outils (Chrome)

Via le bouton Modifier (icône crayon) → Barre d'outils → activer Outils de développement pour un accès en un clic permanent.
