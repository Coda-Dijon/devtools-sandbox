Afficher le code source d'une page

Afficher le code source de cette page (selon l'OS / navigateur). Plusieurs façons de le faire :

  • CTRL + U
  • Command + Option + U
  • Command + U
  • Taper view-source: devant l'URL dans la barre d'adresse
  • Clic droit -> Afficher le code source de la page
